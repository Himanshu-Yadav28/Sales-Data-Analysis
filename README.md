# Sales-Data-Analysis
This project involves analyzing a given sales dataset to extract valuable insights, such as total revenue, best-selling products, and monthly sales trends. By utilizing Python libraries such as Pandas, Matplotlib, and Seaborn, we will perform data cleaning, exploratory data analysis (EDA), and visualization. Additionally, an interactive dashboard is created using Streamlit.

## Key Objectives

- Load and clean the sales dataset.

- Perform exploratory data analysis (EDA) to extract meaningful insights.

- Visualize key metrics such as total revenue, product performance, and sales trends.

- Enhance visualizations using Seaborn for better insights.

- Build an interactive dashboard using Streamlit.

## 🛠️ Tech Stack

- Python

- Pandas

- Matplotlib

- Seaborn

- Streamlit

## 🧭 Expected Insights

- Total Revenue : Calculate overall revenue from sales.

- Best-Selling Products: Identify top-performing products.

- Monthly Trends: Visualize sales patterns over time.

- Category Performance: Compare sales by product categories.
